MSVC (Windows) & GCC (Linux) Optimized

Native Sega Saturn Emulator

SaturnX is a high-performance desktop emulator built on the Beetle Saturn core, offering ultra-low input latency and high emulation accuracy.

🪟 Win64 Release (MSVC) 🐧 Linux x86_64 (GCC) ☁️ Download via MEGA.nz
⚡

Beetle Saturn Core

Delivers maximum rendering accuracy for VDP1/VDP2 hardware and precise emulation of the SCSP audio processor.

🛠️

MSVC & GCC Builds

Codebase optimized with SIMD vector instructions (AVX2/SSE4.2) using native MSVC and GCC compilers.

🎮

Low Input Lag

Direct processing via DirectInput/XInput and SDL2 to ensure minimal controller response time.

System Requirements

  • OS: Windows 10 / Linux 64-bit
  • CPU: Intel Core i5 (4th Gen) / AMD FX-8350 (AVX support)
  • RAM: 4 GB RAM
  • GPU: OpenGL 3.3 / Vulkan 1.1
  • Compiler: MSVC v142+ / GCC 9+
